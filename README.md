# MusicBox

简洁的音乐下载工具。


## 安装依赖
```bash
pip install -r requirements.txt
```


## 运行步骤
1. 执行命令启动工具：
   ```bash
   python musicbox/main.py
   ```
2. 按提示选择是否下载歌词（默认下载）。
3. 选择下载方式（单首/批量）：
   - 单首：输入歌曲名，选择对应结果即可下载。
   - 批量：首次运行会生成`music.txt`，按示例填写歌曲（每行一首），重新运行并选择批量下载。


## 说明
- 下载文件默认保存至`output`文件夹。
- `music.txt`中以`#`开头的行为注释，不参与下载。
- 请遵守版权规定，用于合法用途。
